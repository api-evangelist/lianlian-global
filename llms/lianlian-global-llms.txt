# LianLian Global

> LianLian Global is the cross-border payments arm of LianLian DigiTech, providing licensed collection, disbursement, foreign exchange and card issuing rails between China and the rest of the world. Its developer platform publishes 18 API products and 173 OpenAPI/Swagger specifications covering more than 550 operations.

## Getting started

- [Developer portal](https://developer.lianlianglobal.com): Stoplight-hosted documentation for every API product
- [Authentication (OAuth 2.0, LPPE)](https://developer.lianlianglobal.com/docs/lppe/b6b6c2d4906e9-authentication): client_credentials and authorization_code flows
- [Authentication (API key + RSA signature, B2C)](https://developer.lianlianglobal.com/docs/llp-api/c712e8e5f4a5c-authentication): Authorization Basic header plus LLPAY-Signature
- [Errors](https://developer.lianlianglobal.com/docs/lppe/fbedb06f358ad-errors): error envelope and common error codes
- [Webhooks](https://developer.lianlianglobal.com/docs/lppe/8u4o96gz8w7bq-webhook-overview): event catalogue, signature and retry schedule
- [Versioning](https://developer.lianlianglobal.com/docs/lppe/7mfhske213tl9-versioning): URL-path versioning
- [Data types](https://developer.lianlianglobal.com/docs/lppe/5857aa0278496-data-types): ISO 4217, ISO 3166-2, epoch milliseconds
- [Metadata](https://developer.lianlianglobal.com/docs/lppe/dbba222494009-metadata): key-value annotation limits
